# Togya Plugin

**把一起学习、共同完成的活动体验带进 Discuz X5 社区。**

[English](README.md) · [发布状态](docs/STATUS.md) · [兼容范围](docs/COMPATIBILITY.md) · [隐私边界](docs/PRIVACY.md)

Togya Plugin 是面向 Discuz X5 的 [Togya](https://togya.com) 集成插件，计划提供账号连接、活动主题、阶段进度及经授权的打卡展示，通过后台同步将内容保留在论坛本地。

**最新可下载实验候选为 `1.0.0-alpha.7-x5`，不是 RC 或生产就绪版本。** 实际下载包及校验文件以 [GitHub Releases](https://github.com/yirihan/togya-discuz-plugin/releases) 为准。另见[合成界面预览](docs/PREVIEW.md)及[升级说明](docs/UPGRADING.md)。Alpha.6 及更早候选同步后可能把会员图片暴露在静态地址，不要用于真实私有内容。Alpha.7 保护新图片并按证据清理已知旧副本；旧身份记录丢失时仍须人工核对，不能直接认定升级后安全。

未发布的 Alpha.8 工作源码正在按本地权威实现核对功能与规则：只做脱敏和 DX 通用性适配，不删减功能。旧 Alpha 的关闭开关不代表最终功能范围，具体见[当前状态](docs/STATUS.md)。

[安装与维护草案](docs/INSTALL.zh-CN.md)说明预期安装、密钥、后台同步、升级和卸载方式，不代表相关门禁已经通过。

## 功能介绍

| 功能 | 设计用途 | 独立发行状态 |
| --- | --- | --- |
| 扫码连接账号 | 会员在 Togya 内明确确认，将连接绑定到当前论坛账号，支持解绑 | 真实 SQL 配合合成上游通过；真实扫码批准未运行 |
| 活动主题 | 原生论坛主题及经授权的 Togya 内容 | 官方模型前置适配；八类原生模型与四项 PC/Touch 控制器 HTTP 检查通过，使用合成上游及零奖励；真实上游批准未验 |
| 阶段与打卡展示 | PC、Touch 展示当前查看者有权读取的信息 | 原生只读页面及私有图片 HTTP 权限检查通过；浏览器鉴权 POST、图片解码及旧 Blob 清理另用合成响应验证，不冒充真实上游全链路 |
| 本地展示、后台同步 | 开帖不实时请求 Togya；同步具备锁、超时、退避和状态记录 | 启用态 CLI 已缓存真实匿名公开示例，锁/批次/状态通过；成员同步未认证 |
| 原生任务及互动 | 可选任务事实核验、原生讨论和评分挂接 | 独立验收，不承诺无需集成即可使用 |
| 可配置积分奖励 | 使用论坛积分配置，保留事务、金额核对和重复发奖保护 | 专项测试通过前后端关闭 |

介绍不等于安装、真实账号连接或实际入账已通过。可核验结果更新在[发布状态](docs/STATUS.md)。

## 不是整站替换包

- 产品显示名为 **Togya Plugin**；内部标识保留 `pintogya`，维持路由及协议兼容。
- 不分发完整 Discuz 程序，不以覆盖某个论坛的整套核心文件作为安装方式。
- 不依赖私人维护插件、固定数据库名称或客户域名白名单。
- 论坛原有阅读、发帖、管理及积分权限始终有效。
- 需要额外挂接的功能明确列出，缺挂接时后端拒绝，不只是隐藏按钮。

## 运行要求与安装方向

目标环境是 **Discuz X5、PHP 8.2 以上、HTTPS、InnoDB 事务表**。这是运行要求，不代表已认证所有版本组合；不宣称兼容 X3.x。

RC 将提供完整步骤：核对兼容矩阵并备份、上传发布包、通过 AdminCP 安装、配置站点/版块/用户组、以 Web 服务用户运行后台同步、使用官方全缓存更新并验证 PC/Touch。

安装包不包含生产凭据、客户配置或真实账号数据。运营者使用自己的配置及允许的 Togya 服务访问权限，合成测试不替代真实授权验证。

## 分段发布

1. 介绍预览：公开说明、隐私边界和路线图。
2. 安装候选：完成通用化，在隔离空白 X5 环境验证安装、禁用和卸载。
3. RC：提供固定源码、校验清单、下载包、验收记录和已知限制。
4. 可选扩展：单独适配原生任务、互动和奖励；未验模块后端关闭。
5. 正式版：发布通过验收的 ZIP、维护/升级/恢复说明并核对下载哈希。

GitHub 发布、应用中心提交审核和真正上架分别记录，不互相替代。
