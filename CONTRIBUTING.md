# Contributing

- Use synthetic data and reserved example domains; no customer configuration, logs, screenshots or source history.
- Keep changes scoped and record compatibility, candidate identity and exact checks.
- Preserve authorization, source validation, transactions, idempotency and fail-closed behavior.
- Do not bundle a complete Discuz core; document native integration explicitly.
- Run focused PHP/JS checks; reuse valid evidence rather than unrelated repeated full suites.
- Do not describe static or synthetic tests as a real account connection or credit payout.
